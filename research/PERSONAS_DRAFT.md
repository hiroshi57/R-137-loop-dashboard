## ペルソナ①「佐藤 美咲」— AI活用中のWebマーケター

| 項目 | 内容 |
|------|------|
| 属性 | 32歳・事業会社（EC・従業員150名）のマーケティング担当・マネージャー1歩手前 |
| AIリテラシー | ChatGPT/Claude を日常使用。プロンプトは自己流。エージェントは「聞いたことはある」 |
| 抱える課題 | 広告・SEO・CRM施策が属人化。「AIにもっと任せたいが、何をどう指示すればいいか分からない」 |
| 現在の代替手段 | X/noteでプロンプト集を漁る→自社に合わず放置。Zapierは月額が稟議に通らず断念 |
| 購買行動 | 無料で試す→効果を実感→上司に月5,000円以内で稟議。決裁権は部長 |
| 成功の定義（Job） | **Functional**: 施策の準備時間を半減 / **Social**: 「AI使いこなしてる人」と社内で見られる / **Emotional**: 手探りの不安から解放される |
| 刺さる訴求 | 「あなたの業種の施策ループが最初から1,000本」「コピペ3分でエージェントが動く」 |
| 離脱リスク | 最初の1本で効果を感じないと二度と戻らない → オンボーディング(#041)が生命線 |

### 佐藤さんの1日とタッチポイント
朝: X でAI情報収集（→ #056 SNS運用が接点）/ 昼: 施策会議で「AIでなんとかならない？」と振られる / 夜: noteで事例記事を読む（→ #055 ブログが接点）

## ペルソナ②「田中 宏」— 業務効率化を模索する中堅企業の経営者

| 項目 | 内容 |
|------|------|
| 属性 | 51歳・製造業（従業員80名）代表取締役。DXは号令をかけるが自分では触らない |
| AIリテラシー | 低〜中。「AI活用しろ」と言うが具体イメージなし。日経とセミナーが情報源 |
| 抱える課題 | 人手不足。間接業務のコスト。若手からの「ツール入れてほしい」要望に判断基準がない |
| 現在の代替手段 | ITコンサルに相談（高い）/ 補助金でツール導入したが使われず塩漬け |
| 購買行動 | セミナー・紹介経由。**自分で試さず部下に検証させる**。決裁は即断（年30万円以下なら） |
| 成功の定義（Job） | **Functional**: 間接業務の工数削減を数字で見たい / **Social**: 同業会合で「うちはAI活用してる」と言いたい / **Emotional**: 時流に乗り遅れる恐怖の解消 |
| 刺さる訴求 | 「業種別の活用事例」「導入企業の削減時間」「IT導入補助金対応(#077)」「ワークショップ付き(#076)」 |
| 離脱リスク | 現場が使わない→更新停止。CS(#085)による定着支援が必須 |

### 田中さんへの販路
セミナー(#062)・商工会議所・銀行/税理士の紹介・補助金診断(#077)がフック。**LPからの自然流入はほぼ期待できない**。

## ペルソナ③「鈴木 蓮」— 社内AI推進担当のエンジニア

| 項目 | 内容 |
|------|------|
| 属性 | 28歳・IT企業（従業員500名）の情シス兼AI推進室。Claude Code / Copilot 利用者 |
| AIリテラシー | 高。自分でエージェントを組める。LangChain/Dify も検証済み |
| 抱える課題 | 「全社にAIを広めろ」とミッションを受けたが、**非エンジニア部門に配るコンテンツがない**。自作は時間がない |
| 現在の代替手段 | 社内wiki にプロンプト集を自作 → メンテが追いつかず陳腐化 |
| 購買行動 | 無料枠・APIドキュメント・セキュリティ資料を先に見る。稟議は情シス部長経由、セキュリティチェックシート必須 |
| 成功の定義（Job） | **Functional**: 全部門に配れる「使えるコンテンツ」の確保 / **Social**: 推進担当としての成果報告 / **Emotional**: 「配ったのに使われない」徒労感の回避 |
| 刺さる訴求 | 「チーム共有(#028)」「API(#026)」「Slack連携(#031)」「利用分析で活用率を報告できる(#029)」「SSO/セキュリティ(#035)」 |
| 離脱リスク | セキュリティ審査で落ちる → #035監査・#048法的整備が前提条件 |

### 鈴木さんが有料化を決める瞬間
無料で自部門に配布 → 営業部から「これ便利」の声 → 全社展開の稟議でチームプラン。**PLG(#084)の主役はこの人**。
