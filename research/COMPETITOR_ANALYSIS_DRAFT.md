## ポジショニングマップ

```
            コンテンツ提供型
                 ▲
                 │
   PromptBase    │    ★ DI Loop Library
   FlowGPT       │    （ループ集×業種特化×カスタマイズ）
                 │
 ◄───────────────┼───────────────►
 個人向け        │           企業向け
                 │
   Zapier        │    Make / n8n
   (テンプレート) │    Dify / LangSmith
                 │
                 ▼
            実行基盤提供型
```

**DI Loop Libraryの独自性**: 「実行基盤」ではなく「実行の設計図（ループ）」を、日本語×業種特化×カスタマイズ可能な形で提供する点。競合の多くは (a) 英語圏中心、(b) 汎用プロンプト、(c) 実行ツール寄り。

## 差別化戦略の方向性（仮説）

1. **「業種×サービス」の掛け算カバレッジ** — 汎用プロンプト集との決定的な差。営業資料でも「あなたの業種のループが最初からある」を訴求。
2. **カスタマイザー＝実行までの距離の短さ** — 閲覧→自分用に書き換え→エージェントに貼るまで3分。実行基盤系ツールのような構築作業が不要。
3. **日本語・日本の商習慣前提** — ガードレール（薬機法・景表法等への配慮）を含むループは海外勢が模倣しにくい。
4. **コンサル連携（DI本業とのシナジー）** — ツール販売にとどまらず、ループ設計ワークショップ（#076）で単価を上げる。
